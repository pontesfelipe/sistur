- Só o campo resumo (não o arquivo) é injetado no beni-chat e generate-report; docs sem resumo são ignorados.
- Upload: IA lê o arquivo todo e pré-preenche o resumo (3–6 mil caracteres, texto simples sem markdown, nunca inventar números).
- Edição: "Melhorar com IA" preserva o correto e acrescenta o que falta. Sempre revisão humana antes de salvar.
